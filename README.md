# Астро-бот

Полноценное бесплатное Python-приложение для автоматизации астрологического контента в Telegram.

Приложение локально создаёт ежедневные прогнозы для 12 знаков зодиака, генерирует квадратные графические карточки, публикует их в Telegram-канал по расписанию и отправляет персональные прогнозы подписчикам бота.

> Все основные астрологические расчёты выполняются локально. Платные API и RapidAPI не используются.

## Возможности

### Веб-панель управления

- генерация прогнозов на одну дату или диапазон до 31 дня;
- создание 12 PNG-карточек на каждый день;
- автоматический перенос текста на карточках;
- скачивание всех карточек выбранной даты одним ZIP-архивом;
- настройка Telegram-канала и времени автопубликации;
- просмотр готовых дат и текущего статуса системы.

### Telegram-бот

Команда `/start` запускает пошаговый сбор данных:

1. дата рождения;
2. время рождения;
3. город рождения.

После этого бот рассчитывает и сохраняет:

- знак Солнца;
- знак Луны;
- Асцендент;
- координаты места рождения.

Доступные команды:

| Команда | Назначение |
|---|---|
| `/start` | Создать или обновить натальную карту |
| `/today` | Получить персональный прогноз на сегодня |
| `/mycard` | Посмотреть сохранённые данные натальной карты |
| `/subscribe` | Включить ежедневную рассылку |
| `/unsubscribe` | Отключить ежедневную рассылку |
| `/help` | Показать справку |
| `/cancel` | Отменить текущий диалог регистрации |

### Автоматизация

- ежедневная публикация в Telegram-канал через APScheduler;
- индивидуальная рассылка подписчикам;
- SQLite-база без отдельного сервера баз данных;
- подробные логи запуска, генерации и отправки сообщений;
- бесплатное геокодирование городов через OpenStreetMap Nominatim.

## Требования

- Python 3.10 или новее;
- аккаунт Telegram;
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather);
- токен Telegram-бота.

## Установка

Перейдите в каталог приложения:

```bash
cd astro
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Создайте файл `.env` на основе примера:

```bash
cp .env.example .env
```

В `.env` укажите токен бота:

```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
```

Не добавляйте настоящий токен в Git и не публикуйте его в открытом доступе.

## Запуск

```bash
cd astro
python main.py
```

После запуска веб-панель доступна по адресу:

```text
http://localhost:8000
```

Приложение одновременно запускает:

- Flask-веб-сервер;
- Telegram-бота в режиме polling;
- планировщик ежедневных задач.

При первом запуске автоматически создаются SQLite-таблицы и скачиваются шрифты Noto Sans.

## Настройка Telegram-канала

1. Создайте бота через [@BotFather](https://t.me/BotFather).
2. Добавьте бота в нужный канал.
3. Назначьте бота администратором.
4. Дайте право публиковать сообщения.
5. Откройте веб-панель.
6. В поле **ID канала или группы** укажите:
   - `@username_канала`, если у канала есть публичное имя;
   - числовой ID вида `-1001234567890` для приватного канала.
7. Укажите время публикации и сохраните настройки.
8. Сгенерируйте прогнозы на нужную дату.

> Время автопостинга в текущей версии указывается в UTC. Для публикации в 09:00 по Москве укажите `06:00`.

## Генерация карточек

В веб-панели выберите начальную и конечную даты и нажмите **Сгенерировать контент**.

Для каждого дня будут созданы:

- 12 прогнозов;
- 12 PNG-карточек;
- записи в таблице `scheduled_posts`.

Файлы сохраняются по схеме:

```text
astro/output_cards/YYYY-MM-DD/Овен.png
astro/output_cards/YYYY-MM-DD/Телец.png
...
astro/output_cards/YYYY-MM-DD/Рыбы.png
```

Размер каждой карточки — `1080×1080` пикселей.

## База данных

SQLite-база создаётся автоматически в `astro/astro.db`.

### Таблица `users`

Хранит Telegram ID пользователя, данные рождения, координаты, знаки натальной карты и статус подписки.

### Таблица `scheduled_posts`

Хранит дату, знак зодиака, четыре категории прогноза, путь к карточке и статус публикации.

### Таблица `settings`

Хранит настройки канала и расписания.

## Конфигурация

Основные переменные:

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `TELEGRAM_BOT_TOKEN` | — | Токен Telegram-бота |
| `TELEGRAM_CHANNEL_ID` | — | ID или username канала |
| `POSTING_TIME` | `09:00` | Время публикации |
| `FLASK_PORT` | `8000` | Порт веб-панели |
| `FLASK_SECRET_KEY` | — | Секрет Flask-сессии |
| `DATABASE_PATH` | `astro.db` | Имя файла базы данных |
| `OUTPUT_CARDS_DIR` | `output_cards` | Каталог карточек |
| `FONTS_DIR` | `fonts` | Каталог шрифтов |
| `LOG_LEVEL` | `INFO` | Уровень логирования |

Пути `DATABASE_PATH`, `OUTPUT_CARDS_DIR` и `FONTS_DIR` задаются относительно каталога `astro`, если указать относительное значение.

## Технологии

- **Flask** — веб-интерфейс;
- **python-telegram-bot** — Telegram API;
- **Pillow** — генерация изображений;
- **ephem** — локальные астрономические расчёты;
- **geopy + Nominatim** — поиск координат города;
- **APScheduler** — расписание задач;
- **SQLite** — хранение данных;
- **python-dotenv** — загрузка настроек из `.env`.

## Важные ограничения

- Для корректной работы геокодирования нужен доступ к интернету.
- Если город не найден, приложение использует координаты Москвы как запасной вариант; Асцендент и знак Луны в этом случае могут быть неточными.
- Telegram не позволяет боту первым написать пользователю. Пользователь должен хотя бы один раз открыть бота и отправить `/start`.
- Для публикации в канале бот должен быть администратором.
- Генерация не принимает диапазон больше 31 дня.
- Прогнозы являются развлекательным контентом и не заменяют медицинские, финансовые или иные профессиональные рекомендации.

## Логи

Логи выводятся в консоль workflow и содержат:

- запуск и остановку компонентов;
- инициализацию базы;
- создание карточек;
- генерацию прогнозов;
- отправку постов;
- ошибки геокодирования и Telegram API.

Уровень логирования можно изменить:

```env
LOG_LEVEL=DEBUG
```
