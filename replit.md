# Астро-бот — Автоматизация астрологического контента для Telegram

Приложение для автоматической генерации астрологического контента: графических карточек гороскопов, публикации в Telegram-канал и индивидуальной рассылки подписчикам.

## Run & Operate

- `cd astro && python main.py` — запустить Flask-интерфейс (порт 8000) + Telegram-бот
- Панель управления: `http://localhost:8000`

## Stack

- Python 3.11
- Flask 3.x — веб-интерфейс управления
- python-telegram-bot 20+ — Telegram-бот (async/await)
- Pillow — генератор карточек 1080×1080 px
- ephem — локальные астрологические расчёты
- geopy / Nominatim — геокодирование городов (бесплатно, OpenStreetMap)
- APScheduler (AsyncIOScheduler) — планировщик ежедневной рассылки
- SQLite — база данных (пользователи, посты, настройки)

## Architecture decisions

- Бот и Flask запускаются в одном процессе: Flask в отдельном потоке, бот в asyncio event loop
- Тексты прогнозов детерминированы: MD5(знак + дата + категория) → стабильные тексты при повторной генерации
- Геокодирование через Nominatim (OpenStreetMap) — полностью бесплатно, без API-ключей
- Астрологические расчёты через ephem + ручной расчёт асцендента по формуле
- Шрифты NotoSans скачиваются из GitHub при первом запуске

## Required Secrets

- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather

## Product

- **Веб-интерфейс** `/` — генерация контента на диапазон дат, скачивание ZIP, настройки автопостинга
- **Telegram-бот** — сбор данных рождения, расчёт натальной карты, подписка на рассылку
- **Команды бота**: `/start`, `/today`, `/mycard`, `/subscribe`, `/unsubscribe`, `/help`

## Gotchas

- При смене порта обновить `FLASK_PORT` в `.env` и конфиге workflow
- Планировщик использует UTC — учитывайте разницу с московским временем (+3)
- Для публикации в канал: добавить бота как администратора с правом «Публикация сообщений»
- Бот должен получить хотя бы один `/start` от пользователя перед рассылкой
